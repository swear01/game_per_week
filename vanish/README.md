# Vanish

讓玩家用同一個動作，感覺不同成長率有多大的差別。點中央數字累積餘額，右上角的「躍遷」會在本系走到目標時開放。

39 系正常路線共 2,586 下成長，再按 39 次躍遷或通關。

在 Mac 雙擊 [Vanish.command](Vanish.command)。用 Godot 4.7.2 開啟 [game/project.godot](game/project.godot) 可按 F5 執行。

- 點中央數字或按空白鍵，往當前數列走一項。這一步增加的量會加進餘額。
- 點「躍遷」或按 Enter 進入下一系。右上標多少就從餘額扣多少。第一系的價格是 1.55，第 3 下長到約 1.5607，扣完帶約 0.0107 進入調和系。再點一下加 1，餘額變成約 1.0107。後續的扣款是該系走到目標所需的新增金額，先前結餘和超額都會留下。
- 一般關在解鎖後額外點 2、6、14 下，可讓下一系的目標提前 1、2、3 下。斐波那契首次超過翻倍系的完整目標時，可以直接跳過翻倍系。
- 在最後的 Rayo 系完成符號預算，再按 Vanish 通關。每次重新開啟遊戲，都會從 π 系的初始值 1 開始。

中央是目前餘額，點擊後短暫浮出本次加量；右上顯示躍遷價格。π 系用周長除以兩倍直徑，從 1 逼近 π/2，以多位小數顯示。左上顯示系列與關數。Esc 開啟操作選單，F1 查看本系規則與完整計算。

圓內亮格每下增加半徑，新的圓環會點亮更多整數格點。一維雪崩在中央加一粒沙，滿兩粒時會往左右落下。右上進度條顯示離躍遷還有多遠，達標後仍可繼續點。調和與根號倒數從同一條基線、用固定比例往上疊，疊高時可以從中央餘額數字後方穿過。分出的弦或新層小於畫面能分辨的尺度時，數值依然累進。Golomb 穿孔紙帶的讀頭順著同值段前進。三角數排滿一列時亮起整列；積木分堆以同一批積木排出不同拆法。費波那契將前兩項拼成下一項。圖中只用幾何形狀。

從 Conway 系起，每走一步也增加上一系實際付過的價格。小數、科學記號與大數構造表示不同量級；≈ 表示近似，≥ 表示已知下界。F1 可追溯上一系的價格及各筆增量。數列的索引從新系的第一項開始，累積的餘額接著往上疊。

數學定義可參閱 [Friedman 的樹與圖](https://www.fomarchive.ugent.be/2006-April/010305.html)、[Busy Beaver Challenge](https://bbchallenge.org/link) 和 [Rayo 的定義遊戲](https://web.mit.edu/arayo/www/bignums.html)。
